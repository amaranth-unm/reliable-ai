## Teach from the folder and the long page

The workshop is a reading sprint: get an overview of several articles, preserve their different arguments, map relationships and decide where to read more closely. Theory, interpretation and creative practice are worthwhile reasons to include a text. Checking asks whether the agent represented the argument and relationship fairly, and whether its recommendation fits the reading interest.

Use the page for prompts and prepared comparisons. Use the actual folder and text editor to show what the agent creates and what a correction changes. The page's viewer contains prepared snapshots, not live activity. A full slide deck is unnecessary; at most use a question, workflow and closing reminder.

Participants need an AI assistant and a way to save text. No Zotero, Obsidian, connectors, community plugins or accounts for those apps are required. Keep tool installation out of the workshop.

## A 60-minute route

- 0–5: introduce the reading question and save a first overview (step 1).
- 5–13: choose a reading interest and search parameters; stop retrieval at eight minutes (step 2).
- 13–23: generate short orientation notes for five accessible sources; everyone checks one or two important passages (step 3).
- 23–35: compare the overview, idea map and reading queue. Change the reading interest and ask how the recommendation changes (step 3).
- 35–44: have another agent check one connection or recommendation. Read the passage together and challenge an unhelpful checker suggestion (step 4).
- 44–52: record decisions and compare revised versions. Partners trace one connection and one reading choice; keep a brief methods record (step 5).
- 52–55: optional Obsidian demo from the prepared folder.
- 55–57: optional Zotero citation-import demo.
- 57–60: discuss what someone else can assess from the saved record.

The advertised slot is 50 minutes. For that route: 0–4 introduction, 4–12 retrieval, 12–29 notes/comparison/map/queue, 29–38 checking, 38–44 decisions/handoff, 44–48 brief demos, 48–50 discussion. Use the prepared notes if a reading run is slow. Keep the comparison and one passage check; do not spend that time troubleshooting an app.

## Before teaching

Have the five originals open: Tasioulas, Vallor and Powell in one series; Chander and Squirrel Nation's related dialogue; Goodlad's journal introduction, with its accessible proof. S03 links to S04, while our S05 connections are thematic comparisons. Four sources share a publisher, so record the set's narrow coverage. S05's prepared note covers only proof PDF pages 1 and 6. The session question is “How do arts and humanities perspectives help us think about AI?” The prepared brief selects creative practice as its interest.

Open brief.md, sources.md, the five notes, the overview/map/queue versions, checks.md and decisions.md in the editor. Rehearse the prompts and save each step's exact instructions, tool/date, source IDs, input/output versions and check coverage in prompts.md. Record shared conversation context; use a fresh conversation for the checker when possible. Keep rehearsal files in this repo at workshop-drafts/audit-trails/_local/rehearsal/, which is ignored and excluded from the site. The prepared first version flattens Powell's distinction and recommends reading her last; never call this an observed agent reply.

If live retrieval stalls, switch to the backup set and record it. No paywall troubleshooting or account creation during the timed retrieval. An inaccessible candidate remains a lead. Aim for five accessible sources from up to eight candidates. If fewer are ready after eight minutes, record that and use the backup set. Five orientation notes provide enough complexity to compare coverage and relationships; they are not five close readings. Participants check one or two consequential passages themselves and choose deeper reading for later.

Give the checker the originals as well as the notes. The correction specimen is Powell's “Ethics and practice”, paragraph beginning “This approach suggests”. It explicitly reframes procedures as practices. The bad checker suggestion treats linked essays as duplicates. Ask whether that would erase something useful. The second specimen (C04) invents a direct S05 response and overstates access. Trace it from source register to note, map, queue and decision; then show what remains unchecked. Preserve v1 inputs when creating v2 outputs.

## Three-minute Obsidian demo

Before the workshop, open the extracted humanities-ai folder as a separate vault in an already-installed Obsidian. Rehearse the graph using the prepared files, not the room's live output. Standard Markdown links connect source notes and ideas/ notes; no community plugin is needed.

1. Open idea-map-v2.md and show a labeled connection and its passage basis.
2. Follow the link into S03-powell.md. Open the command palette and choose “Open local graph”.
3. Click an idea note or linked source note, then show the sentence explaining the relationship. The graph draws saved links; it does not establish what the relationship means or whether it is correct.

Use a source note's local graph rather than the whole folder graph, which also includes process files. Keep relation labels in the notes. If Obsidian fails, show idea-map-v2.md and its links in the editor; the exercise is already complete.

Official references: https://help.obsidian.md/Plugins/Graph+view and https://help.obsidian.md/Linking+notes+and+files/Internal+links.

## Two-minute Zotero demo

Have Zotero installed and library.ris ready before the workshop. Rehearse import into a new test collection and check all five records. The supplied RIS contains four blog posts and one journal article, verified citation fields and source IDs in note fields. Check S04's collective author and S05's DOI; proof page locators are not exported as final journal pagination. No article files are bundled.

Show the optional export prompt; if the live file is not ready, use the prepared library.ris. Choose File → Import → A file and use the import wizard's new-collection option. Compare one item with the original article, including the source-ID note. Explain that the citation records moved while the Markdown folder keeps the reading map and decisions. Stop after the comparison; organizing a Zotero library can happen later.

Official reference: https://www.zotero.org/support/kb/importing_standardized_formats.

## Questions for discussion

- Which search parameter changed the starting set?
- Does the overview preserve the difference you found in the text?
- Is a map link an explicit response, a thematic interpretation or an open question?
- Why is an article worth your next twenty minutes? Would a different interest change the route?
- What did you accept or reject from the checker, and why?
- Can you identify the inputs and outputs of each AI step, and which passages remain unchecked?
- What could a reviewer assess from this folder beyond a disclosure that AI was used?

The CHM process files remain an optional live example of chronological process notes alongside a current-state document. Choose excerpts the author is comfortable showing; none are bundled in the public page.
