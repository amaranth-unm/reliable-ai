## Present from the workspace and the long page

Use the page to introduce the question, copy prompts and show prepared comparisons.
Use the actual folder and text editor to demonstrate what an agent creates, what it fails to record, and how a correction reaches a new synthesis.
The page's file viewer is a saved prepared example, not live telemetry.

A second full slide deck is unnecessary for this session. If slides are useful for orientation later, keep them to the question, workflow and closing handoff challenge; link back to the complete page. The folder, original sources and text files carry the demonstration.

## A 60-minute route

- 0–5: introduction; explain delegation and show the first synthesis (step 1).
- 5–15: pairs choose retrieval boundaries; run the bounded search (step 2).
- 15–30: read two accessible sources using the saved protocol (step 3).
- 30–45: audit one consequential claim and check the checker (step 4).
- 45–55: record decisions, compare draft versions and write methods (step 5).
- 55–60: exchange folders; trace one claim and correction; discuss takeaways.

The advertised brown-bag slot is 50 minutes. For that slot, shorten reading to ten minutes and decisions to five. Keep the five-minute handoff.

## Before teaching

Open the downloaded example in the editor; put brief.md, sources.md, one source note, checks.md and the two synthesis versions within easy reach.
Have both linked original essays open. Rerun workshop prompts in fresh conversations and save the actual tool, date, instructions, outputs and checks. The prepared examples deliberately include an overclaim and a bad checker suggestion; never describe them as observed agent responses.

If live retrieval stalls, use the two backup essays and record that choice. They are in one publisher's series and S02 responds to S01. Ask what that relationship means for corroboration and coverage.

Give the reviewer agent the original articles, not just the first agent's notes. Ask the room to read one source passage before accepting a correction. The checker can be wrong too.

## Questions for discussion

- Which retrieval restriction most changed the corpus?
- What could the agent actually access?
- Can you distinguish an author's proposal from measured evidence?
- Who approved each consequential change?
- What would a reviewer need beyond a disclosure saying “AI assisted the research”?
