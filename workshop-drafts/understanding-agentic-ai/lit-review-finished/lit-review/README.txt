Understanding Agentic AI: the finished folder
Reliable AI series, Amaranth, University of New Mexico
https://amaranth.unm.edu/reliable-ai/sessions/understanding-agentic-ai/

This is the lit-review folder as the recorded agent left it on
11 November 2026 (Claude Opus 5.5 in Claude Code), after steps 1 to 6.
Every file is as the agent wrote it, with one exception: a local file path
in the first paragraph of checks.md is replaced with […] for privacy.

brief.md and the three files in instructions/ are the ones you save from
the session page. Everything else the agent wrote: sources.md, notes/,
synthesis.md (version 2), history/synthesis-v1.md, synthesis-log.md,
checks.md (the checker's 22 findings, none applied), CLAUDE.md and
progress.md.

The PDFs are not included. Two of the four (the arXiv papers, S01 and S02)
are under CC BY-NC-SA 4.0; the other two don't state a license that allows
sharing. sources.md gives the link the agent downloaded each one from.
Save them in a folder called pdfs/ with the filenames sources.md gives,
and the folder is complete.
