# How to relate the notes

synthesis.md is the running picture of how the articles relate. Write it from the notes, opening a PDF only to check a passage. Give it a version number and list the notes it includes.

Give each point an ID (P01, P02 …) and keep it through every revision. A new point takes the next unused number; a removed point's number is never reused. Cite sources by their IDs (S01, S02 …).

Sections:

- Where they overlap: the specific claim at stake, the sources and pages, and whether the authors make the connection themselves (one cites or responds to another) or you drew it. Write yours as "Read alongside …". Join sources only where their own sentences address the same question; passages on different questions are not an overlap.
- Where they differ: each position, with pages. Say whether it is a real disagreement or a difference of emphasis or audience.
- What only one offers: for each source, what no other source in the set offers. Check every other note before calling something unique.
- For using AI and for teaching AI: what the set offers each.
- Gaps: what none of the sources addresses, and any author, venue or field the set over-represents.

When new notes arrive, revise the synthesis rather than starting again:

1. Copy the current synthesis.md to history/synthesis-vN.md, where N is its version.
2. Revise it, changing any point the new notes affect.
3. Append an entry to synthesis-log.md: the new version, the notes added, and the point IDs added, changed, and weakened or removed, with reasons. A point counts as changed if you altered or dropped any of its wording, sources or qualifications.

Rules:

- State a source's own emphasis before saying how it serves the brief.
- Don't present a connection you drew as a debate the authors are having.
- Don't hunt for agreement. Where you find one, say who might disagree.
- Cite source IDs and pages for every point. Never drop a point silently.
