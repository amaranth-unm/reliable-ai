# Literature review: starting folder

For the Understanding Agentic AI workshop. This folder holds the files
written during the session, with no articles, notes or synthesis: the agent
finds and writes those when it runs.

- `brief.md`: the question, scope and limits.
- `instructions/`: how to read an article, how to relate the notes and how to
  check the synthesis.
- `CLAUDE.md`: the workflow, which Claude Code reads at the start of every
  session. Other agents read a similar file under another name (Codex reads
  `AGENTS.md`); copy it to that name.
- `progress.md`: where the project stands.

To run it, start your agent in this folder and ask it to run stage 1 in
CLAUDE.md, then stage 2, then stage 3. Stage 4 waits until you have decided
which of the checker's findings to accept.

The agent adds `sources.md`, `pdfs/`, `notes/`, `synthesis.md`,
`synthesis-log.md`, `history/` and `checks.md`.

CLAUDE.md is a prepared version written for the workshop on 2026-11-04. The
one your agent writes in step 6 will differ. Nothing here is a recorded
agent output.
