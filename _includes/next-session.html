{% comment %} The next session, as a full-bleed bar on the home page. Usage: {% include next-session.html session=next_session %} `session` is a page from sessions/ (front matter: title, date, time, location, summary, note). The caller finds it by scanning the sessions folder for the soonest future-dated page — see index.md — so announcing a session is just adding its file; nothing here is retyped by hand. Built on .section-warm (base.css), which is the framework's full-width band: it claims the container's `full` column and re-centres its own contents, so the bar spans the window without any wrapper markup in the page.
