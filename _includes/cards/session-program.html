{% comment %} Session Program — the home page's upcoming sessions, set like a printed program rather than a stack of cards Usage: {% include cards/session-program.html rows=upcoming_sessions today=today %} Parameters: - rows: upcoming session pages, soonest first (required). The first is the next session; the rest are "Later this semester". - today: "%Y-%m-%d" string, for the weeks-away labels (helpers/weeks-away.html) and the link text The next session opens out: a left column with its date set large in red, like the rubricated initial the theme is drawn from, the time and the room; then title, presenter, summary, the flyer's three points side by side, the note and the links. Later sessions are an agenda, one row each: a date column with the weekday and time, then title, presenter and summary, and how many weeks off. Each row is a single link to the session page, which carries the points, so the list stays short however many sessions are announced. Everything but title and date is optional, so a placeholder session still sets as a row. A session's own page stays a short coming-soon page until its date (see _layouts/base.html), and for the next session that page would only repeat what the feature already shows. So until the day its title is plain text and the only link is the flyer; on the day the title links to the page and an "Exercises and materials" button appears. Agenda rows always link: their coming-soon pages add the points the rows leave out. {% endcomment %} {% assign today = include.today %} {% assign next = include.rows | first %} {% assign later = include.rows | slice: 1, 50 %} {::nomarkdown} {% if next %} {% capture next_link %}{% include helpers/link-path.html link=next.url %}{% endcapture %} {% assign next_date = next.date | date: "%Y-%m-%d" %} {% if today and next_date > today %}{% assign next_live = false %}{% else %}{% assign next_live = true %}{% endif %}
