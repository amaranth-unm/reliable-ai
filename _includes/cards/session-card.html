{% comment %} Session Card — a large announcement card modelled on the session flyers Usage: {% include cards/session-card.html rows=all_sessions %} Parameters: - rows: session pages, in the order to show them (required) - today: "%Y-%m-%d" string; a session on or after it is tagged with how far away it is ("Next week", "In 3 weeks"; see helpers/weeks-away.html). A session's own page stays a short coming-soon page until its date (see _layouts/base.html), so the link text says so. - raw: true when included from a layout, which isn't run through Markdown, so the nomarkdown guards would print as text. - plain: true leaves out the title link and the page/flyer links, for the coming-soon page itself, where they would point back at the same page. The band carries the date and time; the session number (kicker) is left out, since the date already orders the list. Reads the same front matter the flyer does: date, time, title, presenter (a name, or a list of names), location, summary, points (a list of { title, text }, the flyer's three bold lines and their one-line descriptions) and flyer (the flyer image's filename in the session's own folder, linked as "View flyer"). Everything but title is optional, so a session without points still renders as a card. The coming-soon page is the one caller now; the home page sets its upcoming sessions with cards/session-program.html. {% endcomment %} {% assign today = include.today %} {% unless include.raw %}{::nomarkdown}{% endunless %} {% if include.rows and include.rows.size > 0 %}
