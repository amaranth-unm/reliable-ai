{% comment %} Session Card — a large announcement card modelled on the session flyers Usage: {% include cards/session-card.html rows=all_sessions %} Parameters: - rows: session pages, in the order to show them (required) - today: "%Y-%m-%d" string; sessions after it are tagged "Coming soon" and one on it "Today". A session's own page stays a short coming-soon page until its date (see _layouts/base.html), so the link text says so. - raw: true when included from a layout, which isn't run through Markdown, so the nomarkdown guards would print as text. - plain: true leaves out the title link and the page/flyer links, for the coming-soon page itself, where they would point back at the same page. Reads the same front matter the flyer does: kicker, title, presenter (a name, or a list of names), time, location, summary, points (a list of { title, text }, the flyer's three bold lines and their one-line descriptions) and flyer (the flyer image's filename in the session's own folder, linked as "View flyer"). Everything but title is optional, so a session without points still renders as a card. {% endcomment %} {% assign today = include.today %} {% unless include.raw %}{::nomarkdown}{% endunless %} {% if include.rows and include.rows.size > 0 %}
